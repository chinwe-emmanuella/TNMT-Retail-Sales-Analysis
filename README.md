# TNMT Retail Sales Performance Analysis

## 📌 Project Overview
This repository contains a data analytics capstone project evaluating sales performance for **TNMT Retail**. The goal is to transform raw sales data into actionable business insights for the Sales Director by building a dynamic, sliceable dashboard in Microsoft Excel.

## 📊 Key Objectives

### 1. Data Engineering & Metrics
* **Revenue Calculation:** Calculated total revenue generated per order.
* **Profit Tracking:** Determined the exact profit margin for every transaction.

### 2. Business Reporting & Analysis
* **Trend Analysis:** Tracked revenue performance over time.
* **Product Performance:** Ranked products by total revenue and calculated percentage contributions across categories.
* **Team Evaluation:** Performance breakdowns by individual sales teams.
* **Geographical Insights:** Mapping sales revenue by state, contextualized against state population and median income levels.

### 3. Dynamic Dashboard Features
* **Sliceable Metrics:** Fully interactive reporting filtered dynamically by **Product Category**.
* **Executive Summary:** Integrated insights box highlighting key operational answers regarding monthly trends and regional correlations.

## 🛠️ Tools Used
* **Microsoft Excel** (Data transformation, modeling, and dashboard creation)
